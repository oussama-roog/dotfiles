# Quickshell for niri

A single morphing "pill" at the top of the screen. At rest it shows workspace
dots, CPU / RAM and the clock; it grows in place into a surface when you open
one, and briefly into an OSD when something happens. Beside it floats a
notification dot: a bell that stretches to the right into a one-line pill when
a notification arrives; click the bell for the list. Its mirror on the left is
the agents dot: Claude Code sessions (working, waiting on you, done) and media,
opening a centre with now playing, plan usage and the session list.

It hangs from the top edge as a notch (Ambxst style). Motion, icons, the
search field and the sliding selection highlight are borrowed from Ambxst.

## Layout

```

Toast.qml           one-line notification shown in NotifPill

  Notifications.qml   notification inbox
```

## Keybindings

All go through `qs ipc call pill <surface>` (`hide` closes the open one).

| Shortcut      | Surface         |
|---------------|-----------------|
| `Mod+Space`   | `launcher`      |
| `Mod+W`       | `web`           |
| `Mod+V`       | `clipboard`     |
| `Mod+Shift+T` | `themes`        |
| `Mod+Shift+W` | `wallpaper`     |
| `Mod+P`       | `power`         |
| `Mod+N`       | `notifications` |
| `Mod+A`       | `claude`        |
| `Mod+T`       | `tasks`         |

Inside a surface: type to search, `Up`/`Down` or `Ctrl+K`/`Ctrl+J` to move
(also in the wallpaper strip and power row, where down moves right), `Enter` to pick, `Esc` or a click
outside to close. Destructive actions (logout, restart, shutdown, deleting a
wallpaper, wiping the clipboard) need a press-and-hold.

In the agents centre `j`/`k` pick a session, `Enter` jumps to its terminal
(through tmux when it runs there) and `x` drops it from the list.

## Claude Code

`~/dotfiles/scripts/claude-qs` is wired into `~/.claude/settings.json` as
Claude Code's hooks (SessionStart, UserPromptSubmit, Pre/PostToolUse,
PostToolUseFailure, PermissionRequest, Notification, Stop, SessionEnd) and its
status line. It keeps `~/.cache/qs-claude/state.json`, which `Claude.qml`
watches. Plan usage (5-hour / weekly) only comes through the status line, so it
updates while a session runs.

Icons use the Phosphor-Bold font, installed by `modules/home/phosphor-icons.nix`.

## Theming

`scripts/theme-switcher.sh` calls `scripts/themes/quickshell.sh`, which writes
the base16 palette to `colors.json`. `services/Theme.qml` watches that file,
so the shell recolours live.

## Settings (`flags.json`)

| Key            | Effect                                   |
|----------------|------------------------------------------|
| `dnd`          | no notification popups (criticals still show) |
| `time12h`      | 12-hour clock                            |
| `clockSeconds` | show seconds                             |
| `showGlyphs`   | kanji instead of icons in headers        |
| `uiScale`      | scale everything                         |
| `reduceMotion` | faster animations                        |
| `uiFont`       | font family (default Inter)              |
| `pillOpacity`  | background opacity of the pill           |

## Tasks

`Mod+T` opens a two-column tasks centre over Taskwarrior 3
(`modules/home/taskwarrior.nix`). The tasks live in `~/.local/share/task`, one
database per machine, outside the repo, so rebuilds never touch them. The
centre reads them with `task export` each time it opens and after every change;
nothing is watched, and `task` in a terminal keeps working alongside it.

- Type to filter; with text in the field the first row is "Add …" and Enter
  adds it, Taskwarrior syntax included: `renew cert due:fri +work pri:H`.
- Left/Right (with the field empty), Ctrl+H/Ctrl+L or Tab switch between
  All / Today / projects / Done. All ends with this week's done tasks, folded.
- Enter ticks the selected task, Ctrl+D done/reopen, Ctrl+S start/stop,
  Ctrl+E edit title, Ctrl+M modify (`due:mon -work project:x`), Ctrl+N note,
  Ctrl+X delete, Ctrl+Z undo.
- In the launcher, `+ text` adds a task without opening the centre.
- While a task is started (Ctrl+S) a thin accent bar runs along
  the bottom of the resting notch.
  The list is read at startup too, so this shows right after login.
