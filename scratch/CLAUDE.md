# Scratchpad

This is a scratchpad for quick questions, opened from a tmux popup.

- Answer short and direct. Lead with the answer; skip preamble and recaps.
- Search the web when the answer may be recent or you are unsure; cite the link.
- Give commands and snippets as plain code blocks so they copy cleanly.
- Don't create or edit files unless asked; this folder is not a project.
