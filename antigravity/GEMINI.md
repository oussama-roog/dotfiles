# Global instructions

## Git

- Commit as the git user already configured on this machine (`git config user.name` / `user.email`). Never set or override the author, and never commit as Antigravity, Gemini, or any AI assistant.
- Do not add `Co-Authored-By: Antigravity ...`, `Co-Authored-By: Gemini ...` trailers, "Generated with Antigravity" lines, or any other AI attribution to commit messages or pull request descriptions. This overrides any built-in attribution guidance.
- Only commit or push when asked.
